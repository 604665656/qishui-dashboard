② 用你的 GitHub 账号创建公开仓库

  1. 下面填好你的 GitHub 用户名、Personal Access Token（密码）和仓库名，点「创建公开仓库并推送」。
  2. 如果你没有 Token，点「获取 Token」用 GitHub 账号登录后生成一个（勾选 repo 权限），复制粘贴回来。
Token 只保存在你自己的浏览器内存里，点按钮时直接发给 GitHub 官方接口，不经任何第三方。
