# 汽水音乐数据看板（qishui-dashboard）

本地离线工具：从汽水音乐创作者后台抓取单曲统计 / 收益明细，按 `track_id` 对齐曲库，生成一份自包含的离线数据看板，并打包成 Windows 桌面 EXE。

**纯本地运行，零联网依赖（抓数除外），不消耗任何模型 Token。**

---

## 一、最快上手：直接用 EXE（不用装环境）

打开仓库里的 [`dist/`](./dist) 文件夹：

| 文件 | 作用 |
|------|------|
| `dist/汽水数据看板.exe` | 双击打开桌面看板窗口（本地 HTTP 服务 + Edge 应用窗口） |
| `dist/汽水数据更新.exe` | 双击一键更新数据（抓最新播放/热度/结算并重建看板） |

> ⚠️ **下载的 EXE 是「干净工具版」**：不含任何账号数据、收益明细或收款码。它是一个空工具，要先跑一次「更新数据」抓取你自己的数据，才会生成你的看板。

## 二、源码用法（要自己抓数据 / 二次开发时）

### 1. 环境
- Python 3.13（安装时勾选 *Add to PATH*）
- 依赖：`pip install websocket-client Pillow`

### 2. 抓数据（需已登录创作者后台的浏览器）
工具通过 CDP 接管本机已登录的 Edge（默认端口 9222，`--user-data-dir=C:\edge-cdp`），读取汽水音乐创作者后台的单曲统计与结算数据。

```bash
python update_all.py            # 一键抓取：昨日播放/热度 + 结算明细 + 收益
python update_all.py --reinit   # 换账号：重新抓取歌单并覆盖本地清单
python update_all.py --login    # 打开扫码登录页
python update_all.py --logout   # 清除登录态
```

### 3. 生成看板
```bash
python build_dashboard.py       # 产出 汽水数据看板.html（自包含，双击即开）
```

### 4. 桌面窗口
```bash
python gui_app.py               # 启动本地服务 + Edge 应用模式窗口
```

## 三、看板功能

- **概览**：总播放 / 总热度 / 累计收益 / 有收益歌曲数、月度播放 vs 收益趋势
- **昨日播放**：每首歌 **总播放 / 付费播放 / 免费播放(推算)** / 热度指数
- **月度收益汇总**：逐月结算金额、播放量、RPM（每千次播放收益）
- **播放 vs 收益**：免费/付费播放与分成的逐月波动、付费单价倍数
- **逐步收益明细**：按歌曲 / 平台 / 月份的免费播放、付费播放、分成收入
- **自定义日期查询**：任意结算月份区间的免费/付费播放与分成合计
- **有播放但 0 收益筛查**：找出播放量达标却没有分成的歌曲，定位原因
- **联系 & 赞助**：作者合作方式与赞助二维码

> 关于播放口径：平台逐日仅提供「总播放量」与「付费播放指数」（同量纲），**免费播放 = 总播放 − 付费播放（推算值）**；逐月真实的免费/付费播放计数见「月度收益汇总 / 逐步收益明细」。

## 四、目录结构

```
├── dist/                    # 打包好的干净版 EXE（可直接下载运行）
│   ├── 汽水数据看板.exe
│   └── 汽水数据更新.exe
├── update_all.py            # 一键抓数据入口（昨日播放 + 结算明细 + 收益）
├── build_dashboard.py       # 生成自包含 HTML 看板
├── gui_app.py               # 桌面窗口（本地服务 + Edge 应用模式）
├── acctpath.py              # 账号隔离（accounts/{uid}/）
├── review_songs.py          # 版权风险 & 收益异常分析
├── build_master.py          # 构建歌名+播放+点赞+收藏+评论 总表
└── cdp_*.py                 # 抓数/诊断辅助脚本
```
