# 汽水音乐数据看板（qishui-dashboard）

本地离线工具：从汽水音乐创作者后台抓取单曲统计 / 收益明细，按 `track_id` 对齐曲库，生成一份自包含的离线数据看板，并打包成 Windows 桌面 EXE。

**纯本地运行，零联网依赖（抓数除外），不消耗任何模型 Token。**

---

## 一、最快上手：直接用 EXE（不用装环境）

打开仓库里的 [`dist/`](./dist) 文件夹：

| 文件 | 作用 |
|------|------|
| `dist/汽水数据看板.exe` | 双击打开桌面看板窗口（本地 HTTP 服务 + Edge 应用窗口） |
| `dist/汽水数据更新.exe` | 双击一键更新数据（抓最新播放/热度/结算并重建看板） |

> ⚠️ **下载的 EXE 是「干净工具版」**：不含任何账号数据、收益明细或收款码。它是一个空工具，要先跑一次「更新数据」抓取你自己的数据，才会生成你的看板。

## 二、源码用法（要自己抓数据 / 二次开发时）

### 1. 环境
- Python 3.13（安装时勾选 *Add to PATH*）
- 依赖：`pip install websocket-client Pillow`

### 2. 抓数据（需已登录创作者后台的浏览器）
工具通过 CDP 接管本机浏览器读取汽水音乐创作者后台的单曲统计与结算数据。

**不限浏览器**：会自动探测本机可用的 Chromium 内核浏览器，按顺序尝试
Edge → Chrome → Chromium → Brave → 360极速 → QQ浏览器（先查注册表 App Paths，再查常见安装路径）。
调试端口首选 9222，被占用时自动换 9223 / 9333；专用登录 profile 默认放在
`%LOCALAPPDATA%\QishuiCDP`（旧版固定的 `C:\edge-cdp` 在部分电脑因权限建不出来，现已自动回退）。

```bash
python update_all.py            # 一键抓取：昨日播放/热度 + 结算明细 + 收益
python update_all.py --reinit   # 换账号：重新抓取歌单并覆盖本地清单
python update_all.py --login    # 打开扫码登录页
python update_all.py --logout   # 清除登录态
```

### 3. 生成看板
```bash
python build_dashboard.py       # 产出 汽水数据看板.html（自包含，双击即开）
```

### 4. 桌面窗口
```bash
python gui_app.py               # 启动本地服务 + Edge 应用模式窗口
```

## 三、看板功能

- **概览**：总播放 / 总热度 / 累计收益 / 有收益歌曲数、月度播放 vs 收益趋势
- **昨日播放**：每首歌 **总播放 / 付费播放 / 免费播放(推算)** / 热度指数
- **月度收益汇总**：逐月结算金额、播放量、RPM（每千次播放收益）
- **播放 vs 收益**：免费/付费播放与分成的逐月波动、付费单价倍数
- **逐步收益明细**：按歌曲 / 平台 / 月份的免费播放、付费播放、分成收入
- **自定义日期查询**：任意结算月份区间的免费/付费播放与分成合计
- **有播放但 0 收益筛查**：找出播放量达标却没有分成的歌曲，定位原因
- **联系 & 赞助**：作者合作方式与赞助二维码

> 关于播放口径：平台逐日仅提供「总播放量」与「付费播放指数」（同量纲），**免费播放 = 总播放 − 付费播放（推算值）**；逐月真实的免费/付费播放计数见「月度收益汇总 / 逐步收益明细」。

### 后台改版适配记录（2026-10）

汽水创作者后台近期改过一次，工具已做相应适配，要点如下：

| 变化 | 旧行为 | 现在的处理 |
|------|--------|-----------|
| 歌曲清单新增 `lunaPlay1d` | 没有，只能逐首调概览 | 作为「最近一日播放」参考列（比概览新一天，但**口径不同**，不能与概览值相加/比较） |
| 概览 `period=1` 数据滞后 | 一直是 T-1 | 现在可能停在 T-2/T-3；工具照实显示 updateTime 对应日期，不再假装「昨日」 |
| 概览当天没刷新 | 仍跑 3000+ 次请求白等 | 先探一首，日期没变就直接沿用上次结果，跳过全部请求 |
| 上架新歌（如 3433→3650） | 不会感知，永远统计不到 | 自动比对后台 total，多了就自动重抓歌单 |
| period 取值 | 只有 1/2 有意义 | 实际支持 1=日 / 2=7日 / 3=30日 / 4=更长区间（工具暂用 1 与 2） |
| CDP 连不上 / 403 | WS 握手被拒、或复用到别的工具的浏览器 | 连接时不发 Origin；记住自己拉起的端口，避免误用别家的调试实例 |

> 提示：如果看板显示的日期落后于今天，是**后台自身没刷新**，不是工具问题；明天再点一次更新即可。

## 五、换电脑 / 别人电脑用不了怎么办

| 现象 | 原因 | 处理 |
|------|------|------|
| 日志提示「未能启动专用浏览器」 | 本机没装 Edge/Chrome，或装在探测不到的位置 | 装一个 Chrome 或 Edge 即可；工具会自动探测（含注册表路径） |
| 提示手动执行一串命令 | 自动启动被安全软件/策略拦了 | 复制日志里的命令到「运行」(Win+R) 执行，浏览器开后再点【登录账号】 |
| 提示「未检测到 CDP / Cookie」 | 浏览器起来了但没登录创作者后台 | 在打开的浏览器里登录 music.douyin.com，再点【更新数据】 |
| 端口 9222 被别的软件占用 | 常见（某些下载/抓包工具） | 已自动改用 9223 / 9333，无需处理 |
| 看板窗口没弹出来 | 默认浏览器缺失 | 工具会退到系统默认浏览器打开 `http://127.0.0.1:端口/__gui__` |

> 专用浏览器用的是**独立 profile 目录**，不影响你日常用的浏览器书签和登录态。
